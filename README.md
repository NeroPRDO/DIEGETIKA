# Diegétika — site estático

Site oficial do Grupo de Estudos de Artes e Filosofias Diegétika, preparado para publicação no GitHub Pages.

## Executar localmente

1. Abra esta pasta diretamente no VS Code.
2. Abra `index.html`.
3. Use **Open with Live Server**.

A pasta `.vscode/` já define `index.html` como página inicial do Live Server.

## Onde editar

- `content/site.js`: identidade e textos globais.
- `content/pages/`: títulos, banners e textos específicos de cada página.
- `content/data/`: integrantes, notícias, galeria, atividades, parceiros, redes e mídia.
- `content/producoes/`: conteúdo completo de cada produção.
- `content/data/midias.js`: caminhos, descrições, créditos e enquadramentos de todas as imagens.

Consulte `docs/GUIA_DE_CONTEUDO.md` para manutenção geral.
